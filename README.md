# EPS Master — source code prototipe

## Menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. `chapters.json` berisi data Bab 1–60.

## Fitur yang ada pada prototipe
- Pilihan Bab 1–60, pencarian, dan filter jilid.
- Tryout pilihan ganda, nilai otomatis, pembahasan, dan riwayat lokal.
- Riwayat disimpan pada browser/perangkat ini.

## Batasan
- Ini prototipe front-end: belum ada login sungguhan, backend/database, sinkronisasi lintas perangkat, atau generator AI.
- Bank soal belum lengkap untuk semua bab; beberapa bab masih memakai soal fallback. Jangan dipublikasikan sebagai bank soal lengkap sebelum dilengkapi dan ditinjau.
- Judul dan ringkasan Bab 38–40 serta 44–52 telah diisi pada data aplikasi. Ringkasan adalah ringkasan topik, bukan kutipan lengkap isi halaman; verifikasi langsung dengan PDF sebelum digunakan sebagai materi resmi.
- Soal harus dibuat baru dan diperiksa agar tidak menyalin soal latihan buku.
